# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for the teaching mission.
Knowledge should be drawn from these sources rather than unsupported guesses.

## Structure

```md
# {Topic} Resources
## Knowledge

- [Title](https://example.com)
  What it covers and when to use it.

## Wisdom (Communities)

- [Community](https://example.com)
  What high-signal feedback it provides.

## Gaps

- {Important topic for the mission without a trustworthy source}
```

## Rules

- Prefer primary sources, recognized experts, peer-reviewed work, repository
  code/tests, and well-moderated communities.
- Annotate every entry; a bare link is not enough.
- Keep Knowledge and Wisdom separate.
- Surface missing sources explicitly and prune sources that prove shallow or
  wrong.
- Record when the user has opted out of community participation.
