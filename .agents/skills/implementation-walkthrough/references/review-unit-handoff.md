# Review Unit Handoff Reference

Use this compact contract for each consequential Review Unit:

```text
## RU-03 — Route authorization

Purpose
What behavior or contract this unit owns.

Risk
Critical | High | Medium | Low

Failure modes
What could go wrong if this implementation is incorrect.

Files
Must-read:
- ...

Supporting:
- ...

Proof/test:
- ...

Dependencies
RU-01 → RU-02 → RU-03

Observed path
Request → ...

Architecture questions
Questions that must be resolved from the codebase.

Risk Probes
Targeted searches or inspections performed or recommended.

Test evidence
What is demonstrated, with freshness classified.

Unverified
What evidence is missing or unavailable.

Invariant
What observable property should remain stable.

Formal review
Pending code-review
```

The completed walkthrough should also include a compact progress matrix with
Review Unit, Risk, Source traced, Critical path, Test evidence, Invariant, and
Formal review columns.
